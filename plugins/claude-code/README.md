# Perafly plugin for Claude Code

The plugin adds the Perafly MCP server (`npx -y perafly mcp`) and the `perafly` skill. Sign in first with
`perafly login --access agent`, or use `perafly setup agent --agent claude-code`, which writes the same
configuration with your installed CLI. `skills/perafly/SKILL.md` is a copy of the package's `skills/perafly/SKILL.md`
(a test keeps them identical).
