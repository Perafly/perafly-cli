# Perafly for Cursor

Copy `mcp.json` into `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` (one project), or run
`perafly setup agent --agent cursor`. Sign in first with `perafly login --access agent`.

Hosted server instead of the local one (OAuth in Cursor): `{ "mcpServers": { "perafly": { "url": "https://mcp.perafly.com" } } }`.
